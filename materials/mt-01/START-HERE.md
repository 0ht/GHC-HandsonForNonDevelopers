# MT-01：会議メモを「やること一覧」にする

> 学習用の架空データを使用する。実際の業務データを追加しない。

## はじめ方

1. ZIP を展開する。
2. GitHub Copilot App で、このファイルが入っている mt-01 フォルダーをローカルフォルダーとして追加する。
3. このフォルダーの作業用セッションを Interactive で開始する。
4. ハンズオンの Web ページに戻り、順番に依頼文を入力する。

## 入っているもの

| 場所 | 内容 |
| --- | --- |
| input/meeting-notes.md | Copilot に読んでもらう議事メモ。自分でも開いて確認する。 |
| output/README.md | 成果物を保存する場所の案内。 |

Skill・MCP・Office アプリの追加導入は不要とする。GitHub Copilot App、Git、GitHub アカウント、利用可能な Copilot プラン、組織の利用許可は事前に準備する。

## 安全に進める

原本を変更・削除しない。メール送信や外部サービスへの投稿は行わない。操作の許可要求は内容を確認してから判断し、予想と違う操作なら停止する。ローカルファイルでも、AI の処理に使う内容は利用サービスに送信され得る。
