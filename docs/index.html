はじめる前に

App の準備を先に済ませると、演習の20分を作業に使えます。

  1. App を準備する

    GitHub Copilot App と Git をインストールし、GitHub にサインインします。利用可能な Copilot プランが必要です。

  2. 演習の教材を開く

    演習ページから ZIP をダウンロードして展開します。App に、展開した教材フォルダーを追加します。

  3. 依頼して、確かめる

    依頼文をコピーして試します。作成されたファイルを開き、元のメモと照合します。

公式のセットアップ手順を開く

組織のアカウントを使う方は、App の利用許可とデータ利用規程を確認してください。演習中もネットワーク接続が必要です。教材は架空のデータなので、実際の業務資料を用意する必要はありません。

よくある質問

コードや Git の操作を知っている必要はありますか

コードの入力や Git コマンドの操作は行いません。フォルダーを開く、文章を貼り付ける、できたファイルを確認する操作で進めます。Git のインストールは App の事前準備に含みます。

何かを購入したり、追加設定したりしますか

利用可能な Copilot プランは事前に必要です。演習用の教材はこのサイトから取得します。Office アプリ、Skill、MCP などの拡張機能は追加しません。

実際の仕事のファイルでも試せますか

まずは配布教材で操作を確認してください。PC内のファイルも、AI が処理する内容は利用サービスに送信される場合があります。実データを使う前に組織の規程を確認し、個人情報や機密情報を入力しないでください。

途中で操作に迷ったら

演習ページ末尾の「困ったときは」を確認してください。想定していない操作の許可を求められた場合は、許可せず App の Stop で止めてください。
