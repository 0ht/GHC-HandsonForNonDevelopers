# 非開発者向け GitHub Copilot App ハンズオン

> 本リポジトリは学習・検証用とする。演習には架空のデータを使用し、実際の業務データや本番環境は扱わない。

[参加者向けサイト「GitHub Copilot 活用100選」](https://0ht.github.io/GHC-HandsonForNonDevelopers/)

プログラミング経験のない業務担当者が、GitHub Copilot App を使って日常業務を効率化するためのハンズオン設計資料をまとめる。「依頼する → 作業を進める → 根拠と成果物を確認する → 改善する」を学ぶ。

## 公開・更新

GitHub Pages の公開元は `0ht-non-developer-hands-on` ブランチの `/docs` とする。このブランチに変更をコミットしてプッシュすると、Pages が再デプロイする。公開元を別のブランチに移す場合は、Settings → Pages の設定も変更する。

サイトとして配信するのは docs 配下だけとする。リポジトリ自体は Public のため、設計資料・講師用資料・コミット履歴も GitHub 上で閲覧できる。教材の更新後は `pwsh -File .\scripts\build-materials.ps1` で ZIP を再生成し、教材原本と併せてコミットする。

## 標準版と発展版

| 区分 | 内容 | 前提 |
| --- | --- | --- |
| 標準版 | ローカルのテキスト・Markdown を使い、エージェントに読取・整理・作成を依頼する。 | 共通準備 P0 と各シナリオの前提。Skill・MCP 等の追加導入は必須にしない。 |
| 発展版 | 同じ題材に Skill、カスタムエージェント、MCP、Canvas、Automation 等を追加する構成案。 | 要素ごとの導入・契約・認証・権限・依存関係を確認し、標準版とは別に時間を見積もる。 |

シナリオ集の所要時間は標準版の目安とする。発展版の追加要素は選択肢であり、すべてを導入する必要はない。機能一覧の 32 要素すべてを、標準版の 100 件で学べるという意味ではない。
